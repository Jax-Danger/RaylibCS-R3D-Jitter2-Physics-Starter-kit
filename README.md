# RaylibCS-R3D-Jitter2-Physics-Starter-kit
This is a starter kit to get a quick 3D game up and running with physics, lighting and shadows. It's complete with a custom map from Blender, as well as a basic player.


# how to setup this project:
1. Download repository or clone
2. Open the folder with your IDE of choice.
3. Open your IDE's console. If using VSCode, default keybind is Ctrl and J.
4. type `dotnet run`


# dependencies for this project:
1. .NET 10.0+

## Note:
This project is built with .NET 10.0, and already has the following packages installed:
1. Jitter2 Physics
2. R3D_cs(for lighting and shadows)
3. Raylib_cs(comes with R3D_cs)
